# 28 — Feature inventory against every promise, 2026-11-09

**Purpose.** One table per place where Pactora promised a feature, with the
state of each promise in the code on branch `human-work` as of today, where
the evidence is, what is missing and whose work it is. Then the features a
marketplace user expects that nobody planned, the submission rules of
[docs/24 §1.1](24-near-hackathon.md), and the owner decisions
still open. Written for the hackathon submission (deadline 2026-11-14
23:59 UTC) and for whoever picks the work up after it.

**Date.** First written on the morning of 2026-11-09; brought up to the
final state of branch `human-work` the same night, against the committed
heads: contracts `08453d2` (1.1.0, no source change since `25df5c3`),
backend `cb19e32` (round 3 at `9b8ff67`: history, audit-log export, indexer
stall, the swarm; then the deadlock fix), interface `3167193` (README "Built
on 2026-11-09", round 3), docs `0e3aedc` plus this change. Every status
below was re-checked in the code at those commits, not taken from a commit
message. The backend's `PROGRESS.md` is cited as it stood in its working
tree, where another agent was recording the deadlock fix.

**Status values.**

| Status | Meaning |
|---|---|
| done with test | the code is in the tree and a test in the tree exercises it; both are cited |
| done | the code is in the tree; the proof is a live run or a gate, not a unit test |
| partial | some of the promise is built; the "What is missing" cell says which part is not |
| missing | nothing in the tree does it |
| owner-blocked | needs a key, an account, money, a vendor or a decision only the owner can give |

**Evidence rule.** Every Evidence cell is one or more `repo path:line`
references in backticks; the short form `` `:N` `` used in the first edition
is gone, every citation names its repo and file. Lines are cited to
implement or test the feature, not to mention it. A script in the author's
scratchpad opened each citation and checked that the file exists and the
line is not blank; the count and result of the last run are in the
"Citation check" line at the end of this document. Citations from the first
edition were carried to the current lines by diffing each file from the
commit it was cited against to the current head; the ones whose line had
changed were re-pointed by hand. Rows that rested on the withdrawn docs
(11, 12, 17–23) were dropped in the first rewrite; none remain. Repo names
are shortened nowhere: `pactora-docs-near`, `pactora-contracts-near`,
`pactora-backend-near`, `pactora-interface-near`.

Who column: **built** (on `human-work`, before or during 2026-11-09),
**owner**, **future** (nobody is on it; for most of these it waits on a
contract release after 1.1.0, a vendor, or a decision).
